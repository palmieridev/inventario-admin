# Contratos compartidos

Tipos de solicitudes y respuestas compartidos por frontend y backend. Este paquete no contiene conexiones, credenciales ni lógica de persistencia.

Los consumidores lo declaran como `@inventario/contracts: workspace:*`. La compilación genera JavaScript ESM y declaraciones TypeScript en `dist/`; los scripts de la raíz lo construyen antes de iniciar las aplicaciones.
